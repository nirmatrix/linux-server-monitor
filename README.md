# Centralized Report Building System

A Bash-based centralized system monitoring and report generation project designed to collect important system information and generate organized health reports for Linux environments.

## 📌 Project Overview

This project collects important system information such as:

- Disk usage
- Memory usage
- System uptime
- CPU load
- Running processes
- System date and time

The collected information is then organized into a centralized report format for easier monitoring and analysis.

## 🎯 Project Goals

- Practice Linux and Bash scripting
- Improve automation and monitoring knowledge
- Understand system resource tracking
- Learn report generation concepts
- Build a beginner-friendly DevOps-style mini project

## 🛠 Technologies Used

- Bash Scripting
- Linux Commands
- WSL2 / Linux Environment

## 📂 Features

- Centralized report generation
- Organized system health output
- Human-readable reports
- Beginner-friendly script structure
- Modular function-based scripting

## 📄 Report Information

The generated report may include:

- Current date and time
- Disk usage status
- RAM usage
- CPU information
- System uptime
- Active processes
